# STOCK/86 — Used Gaming Hardware

A clean, mobile-first storefront for used consoles, handhelds, and games based in Koura, Lebanon.

## What's in the store

- **Nintendo Switch** — modded units with full accessories
- **Switch Games** — physical cartridges, tested and working
- **Handhelds & Consoles** — AYANEO, ROG Ally, Xbox, and more
- **Laptops** — tested, functional units

## How it works

1. Browse listings on the homepage
2. Add items to cart
3. Pay via **Whish Money** QR code at checkout
4. Confirm your order on **WhatsApp**
5. Flat **$10 delivery** anywhere in Lebanon

## Tech

- Pure HTML, CSS, JavaScript — no frameworks
- Hosted on GitHub Pages
- Mobile-first responsive design
